Two worlds.

The living reference for Maya Universe and Ellie Universe – the simulation series built to help learners navigate job searching, interviews, and starting work.

What is this
A shared reference for the simulation universes built by our L&D team. It maps the narrative, the characters, the learning objectives, and the production rules.
Why we built it
So that any ID joining the project can understand the world they’re building into – and add to it without creating inconsistencies in story, character, or learning design.
How to use it
Start with a Universe Map to understand the narrative arc and gaps. Then open the Circle to explore the characters in depth.
