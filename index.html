Overview
What Is This
A shared reference for two simulation universes built by our L&D team. It maps the narrative, the characters, the learning objectives, and everything IDs need to build what comes next.
Why We Built It
So that any ID joining the project can understand the world they’re building into – and add to it without creating inconsistencies in story, character, or learning design.
How to Use It
Use the tabs above to navigate between documents. Start with a Universe Map to understand the arc, then open the Circle to explore the characters in depth.
